``sphinx-matlab-apidoc`` templates
==================================

``sphinx-matlab-apidoc`` renders two `Jinja <https://jinja.palletsprojects.com/>`_
templates, which ``-t`` can replace (:doc:`../user-guide/apidoc`). The
defaults are in ``sphinxcontrib/matlab_apidoc/templates/``. They are
rendered with Sphinx's ``ReSTRenderer``, which adds the filters ``e``
(escape reST) and ``heading`` (underline a title; ``heading(2)`` for the
second level).

The variables below are a public interface: new ones may be added in any
release, but renaming or removing one is a breaking change. Every generated
file starts with the marker line ``.. Generated by sphinx-matlab-apidoc.``,
which the command adds outside the templates.

``folder.rst.jinja``
--------------------

One page per folder.

``docname``
   The page, relative to the output folder, without suffix
   (``+demo/index``).
``ref``
   The folder's path reference (``+demo/``; ``./`` for the root).
``title``
   The folder's signature: ``namespace demo``, ``folder utils/``, or
   ``folder ./``.
``kind``
   ``"namespace"``, ``"folder"`` or ``"root"``.
``is_root``
   True for the root folder's page.
``sections``
   ``(title, entries)`` pairs in the order Classes, Functions, Scripts,
   Apps; only sections with entries. ``entries`` are described below.
``subfolders``
   The docnames of the subfolders' pages, relative to this page:
   namespaces, then folders, then ``private/``.
``separate``
   True with ``--separate``.
``maxdepth``
   The value of ``--maxdepth``.

Entries
~~~~~~~

Each entry describes one file:

``ref``
   The file's path reference.
``kind``
   ``"class"``, ``"function"``, ``"script"`` or ``"application"``.
``directive``
   The auto directive, such as ``"mat:autoclass"``.
``options``
   A dictionary of directive options; ``{"members": "", "undoc-members":
   "", "show-inheritance": ""}`` for classes, else empty.
``title``
   The heading: the MATLAB name, or the path reference if MATLAB cannot
   call the file.
``display``
   The name signatures show (the same as ``title``).
``matlab_name``
   The MATLAB name, or ``None`` if MATLAB cannot call the file.
``callable``
   ``matlab_name is not None``.
``private``
   True for files below ``private/``.
``docname``
   With ``--separate``: the file's page, relative to the folder page.
   Otherwise ``None``.

``object.rst.jinja``
--------------------

With ``--separate``, one page per file. It gets the variables of one entry,
with ``docname`` relative to the output folder.
